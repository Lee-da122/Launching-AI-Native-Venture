# MVP Scope

## In scope

### Account and profile
- Sign up
- Login / logout
- Create matching profile during sign-up
- University email required
- Skills
- Availability + Flexible / Negotiable
- Preferred role
- Working style
- Project goal / effort level

### Competition flow
- Seeded competition list
- Competition search
- Select a competition

### Join a Team
- View recruiting teams
- Compatibility score
- Match explanation
- Shortlist
- Apply
- Application status

### Recruit a Team
- Create team recruiting post
- Define needed skills
- Define needed role
- Define availability
- Define working style preference
- Define effort level
- Define number of members needed
- View applicants
- Applicant compatibility
- Accept / reject applicant

### Database
- users
- competitions
- teams
- applications
- shortlists

## Out of scope

- Real email verification
- OAuth / Google login
- Messaging
- Payments
- Real-time notifications
- Calendar integration
- External competition APIs
- Complex AI agents
- Automatic good/bad teammate ranking
- Participation monitoring after the project starts

## Definition of Done

A user can:
1. create an account and matching profile,
2. log in,
3. choose Join or Recruit,
4. search/select a competition,
5. either apply to a compatible recruiting team or publish a recruiting post,
6. see explainable compatibility results,
7. keep the final decision in human hands.
